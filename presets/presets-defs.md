# 代表60音

## ベース

| #音源要件 |                   |                                                                                                                                                                                      |
| ----- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1     | **クリーン・サブベース**    | 曲の最低域を安定して支える純度の高いサブベース。Sineの基音を中心に、Triangleによる控えめな低中域の補強だけで構成する。長音でも濁りや揺れがなく、短音でも輪郭がぼやけない。キックや他の低音と重ねて低域の厚みを自然に補う用途に適する。 |
| 2     | **808ベース**        | 発音直後の大きな音程下降と、その後に続く深く滑らかな低音が特徴の808系ベース。Sine基音に軽いSaturationを加え、低域中心のまま小さなスピーカーにも存在感を残す。短い音では落下感が明確に現れ、長音では下降後の音程が安定して低域を支え続ける。 |
| 3     | **アナログ・ソウベース**    | 太いSaw倍音とSub Sineの芯を持つ、標準的なアナログ系シンセベース。Ladder FilterとFilter Envelopeにより、発音直後の適度な明るさと勢いから丸く落ち着いた持続へ移る。House、Techno、Synth Popなど幅広い楽曲のベースラインに使える汎用性を持つ。 |
| 4     | **ショート・プラックベース**  | 8分・16分音符の刻みに適した、短く弾むプラックベース。減衰のみで進むEnvelopeと速いFilter Envelopeが明確な輪郭を作り、連続発音しても前の音が次の音へ大きく重ならない。Sustainを持たないため長押しでも一定音量で伸びず、短い音の中にもSub Sineによる低音の芯と音程感が残る。 |
| 5     | **303系アシッドベース**   | 鋭い共鳴と大きな音色変化が特徴の、303系アシッドベース。高ResonanceのLadder Filterへ深いFilter Envelopeを与え、発音直後の鋭いピークから粘りのある暗い持続へ落ちる。VelocityがFilterを開くため、反復する短いフレーズにアクセントを付けやすい。C1〜C4付近で高い共鳴成分と低域のベース成分が一体になって響く。 |
| 6     | **FMパンチベース**      | 硬い立ち上がりと引き締まった低域を持つFM系ベース。基音に対する変調指標を発音直後に大きくして即座に落とすことで、デジタルらしい複雑で鋭い倍音から単純で安定した低音への移行を作る。高い倍音の比率を持つ補助Modulatorが極短時間の打撃感を加え、キックと並んでも発音位置が分かる。金属的な要素を含みつつ音程感は強く、短いフレーズでも存在感がある。 |
| 7     | **リースベース**        | 太く暗く、内部にゆっくりしたうねりを持つ持続ベース。複数VoiceのDetuneしたSawが低いビート音の唸りを作り、Sub Sineが中央の低域の芯を固定する。低速のLFOがFilterとDetune幅を揺らし、長音の内部に継続的な動きを与える。Drum & Bass、Techno、Industrial系の背景を支える密度の高い低音。 |
| 8     | **デジタル・モーションベース** | 1音の途中でWavetableの走査位置が変化し、低域の基音を保ちながら中域から高域の倍音構成が連続的に変化するデジタルベース。Sub Sineが低域の芯を支え、動く倍音の質感が短い音から長い音まで展開する。単純な音量変化や周期的な揺れとは異なる、音形の連続的な変形が特徴。 |
| 9     | **ウェーブフォールド・グロウルベース** | 低域の安定した芯の上に、折り返しによる荒い倍音を重ねた攻撃的なベース。Wavefoldを深くかけたSawが中域の唸るような質感を作り、低速のLFOが折り返し量をゆっくり動かして倍音の密度と明るさを連続的に変化させる。Sub Sineが低い音でも基音の位置を明確に保ち、短い音では硬い輪郭を持つ。Bass Music、Industrial、重いElectro系で前面に出せる。 |

## リード

| #音源要件 |                |                                                                                                                                                     |
| ----- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 10    | **アナログ・ソウリード** | メロディやソロに広く使える、標準的なシンセリード。軽いDetuneを持つ複数VoiceのSawが適度な太さを作り、Ladder Filterの軽いDriveがアナログ的な暖かさを添える。高音域でも刺激が強すぎず、低音域でもベースのような重さには寄らない、汎用リードの基準となる音。 |
| 11    | **スーパーソウ・リード** | TranceやEDMの前面を担う、厚く広がりのあるスーパーソウ系リード。多数のDetuneしたSawと広いStereo配置により、単音でも複数の音のずれを明確に感じさせ、コードでは大きな音の壁を作る。中央の芯を残したまま左右へ広く開き、Chorusが華やかな厚みを加える。アナログ・ソウリードより明らかに大規模な音。 |
| 12    | **パルス・リード**    | SquareやPulse系を連想させる、細身で明快な電子リード。Pulse波の輪郭を優先し、厚みよりも各音の芯と音程の明確さを取る。C3からC7付近まで性格が変わらず、高音域でも音の芯が残る。ゲーム音楽、Electro、Synth Popの旋律に適する。 |
| 13    | **FMデジタルリード**  | FM音源らしい硬質で精密な倍音を持つデジタルリード。変調を保持中も持続させるため、発音直後から音の終わりまでデジタルらしい複雑さが続く。高い比率の第2Carrierが倍音の支えを加え、金属感と明確な音程感を両立する。ベルのように自然減衰せず、鍵盤を押している間はリードとして持続する。速いフレーズでも音程と輪郭が明確。 |
| 14    | **ハードシンク・リード** | 古典的なシンセサイザーのハードシンクを代表する、鋭く派手なリード。発音直後は高いSync Ratioを持ち、短い時間で落ち着くことで、基音の音程は安定したまま上側の倍音が大きく移動する。通常のソウリードより攻撃的で、FMとは異なる引き裂かれるような質感。中高音域のソロで強い存在感を発揮する。 |
| 15    | **モノ・ポルタメントリード** | 単音のフレーズを滑らかにつなぐ、太く前面に出るモノフォニックリード。Legatoで音をつなぐと前の音から次の音へ滑らかに移動し、離して弾いた場合は各音の発音が明確になる。Unison SawとSub Sineの厚みに軽いDriveが加わり、ソロやフックで前面に出る。速い旋律でも音程の中心を失わない。 |
| 16    | **フェイズディストーション・リード** | 波形の時間方向の形を強く変形させ、鋭く独特な倍音を生むデジタル系リード。Sine基音の位相を歪ませるPhase Distortionが、通常のパルスやソウより硬く、FMほど金属的ではない中間的な質感を作る。保持中は低速のLFOが変形量を動かし、明るさだけでなく倍音の並び方そのものが連続的に変化する。80年代的なデジタル感から現代的な攻撃音まで幅広く使える。 |

## パッド／空間音

| #音源要件 |                       |                                                                                                                                              |
| ----- | --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 17    | **ウォーム・アナログパッド**      | コードの背景を柔らかく支える、標準的なアナログ系パッド。Sawの軽いDetuneにTriangleの温かさを重ね、Ladder Filterで高域を穏やかに丸める。緩やかな立ち上がりと自然な余韻が長時間鳴らしても邪魔にならず、C2〜C6程度のコードでも各音の関係が分かる。派手な変化よりも安定感を優先した、汎用パッドの基準となる音。 |
| 18    | **ダーク・アンビエントパッド**     | 暗く沈んだ雰囲気を作るアンビエントパッド。TriangleとSineだけで倍音を絞り、低いLadder Filterが明るい成分を抑える。2.5秒の立ち上がりでゆっくり存在感が現れ、長いReverbが少し遠くで鳴るような奥行きを与える。低中域を中心に深く、Ambient、Cinematic、暗い電子音楽の背景に適する。 |
| 19    | **ブライト・ワイドパッド**       | 明るい高域と大きな左右方向の広がりを持つ華やかなパッド。22 centのDetuneを持つ7 Voice Unisonが、単音でも複数の音のずれを感じさせ、コードを大きく左右へ開く。0.9秒の立ち上がりはスーパーソウリードより確実に遅く、Chorusと合わせて背景へ馴染む。複数音を重ねても透明感と広がりが残る。 |
| 20    | **PWMパッド**            | 長く保持すると内部の倍音が呼吸するように変化する、古典的なPWMパッド。幅の異なる2つのPulse波へ逆位相のLFOでPulse Widthを動かし、音程そのものではなく厚みと空洞感を周期的に変える。立ち上がりと余韻は長く、コードの背景として継続的に使いやすい。静止したアナログパッドより内部の動きが明確。 |
| 21    | **ウェーブテーブル・モーションパッド** | 長いコードの中で倍音構成が別の形へ移り変わるデジタル系パッド。SineからOrgan、Hollow、Bright、Complexへと並ぶ12フレームのWavetableを、発音してから7秒ほどかけて単方向に走査する。開始時と後半で音色が明確に変わり、その間は滑らかにつながる。一定周期の揺れではなく時間方向の展開が特徴の、人工的で複雑な質感。 |
| 22    | **ボーカル・フォルマントパッド**    | 「アー」「オー」「ウー」の母音共鳴を連想させる合成パッド。48 PartialのSine列へ母音3 ProfileのFormantを適用し、低速のLFOが母音位置をゆっくり往復させて口の形が動くような感覚を作る。柔らかなSawのBody層が全音域の土台を支え、帯域に余裕を持たせた共鳴がコードでも鋭く突出しない声質を保つ。合唱を思わせつつ、明確に電子音として聞こえる。 |
| 23    | **アディティブ・ドローン** | 1音を長く伸ばしている間に、一部の倍音が4〜12秒かけて浮かび上がったり沈んだりするドローン。12個のPartialのうち固定の4個が低中域の土台を維持し、残る8個が個別のEnvelopeで時間展開する。さらに8個の倍音バランスがゆっくり不規則に移り変わり、保持中も変化が続く。控えめな残響が奥行きを添え、AmbientやCinematicの背景に適する。 |
| 24    | **グラニュラー・テクスチャパッド** | 細かな音の粒が重なり合いながら持続する、粒状感のある広いパッド。倍音と空気を含む3秒のテクスチャSourceをGrainへ分解し、RandomnessとPan Spreadで粒を前後左右に散らす。低速のLFOが読み取り位置を漂わせ、長音の内部に絶えず細かな変化を生む。全体の音程感は保ちながら、表面は少し霞んだ広がりを持つ。 |

## キー／ポリシンセ／コード

| #音源要件 |                  |                                                                                                                                                           |
| ----- | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 25    | **FMエレクトリックピアノ** | 1980年代のFM音源を代表するエレクトリックピアノ。比率1の変調が発音直後に強くかかって硬く明るい打撃感を作り、減衰とともに暖かく丸い持続音へ移る。比率14の短命な第2Carrierがタインのきらめきを加える。Velocityが変調指数を動かすため、強い打鍵では明るく硬く、弱い打鍵では丸く穏やかに響く。4〜6音のコードでも自然にまとまる。 |
| 26    | **トーンホイール・オルガン** | Hammond系オルガンを連想させる、倍音が規則的に積み重なる持続鍵盤音。9本のドローバーに対応する0.5〜8倍のSine Partial（サブオクターブ、クイント、5倍音を含む）を加算し、単音でも複数の倍音が明確に聞こえる。鍵盤を押している間はほぼ一定の音量で鳴り続け、コードでは厚い和音を形成する。軽いChorusが回転スピーカー風のうるおいを添える素のオルガン音。 |
| 27    | **クラシック・アナログポリシンセ** | コード、伴奏、短いメロディのいずれにも使える、標準的なポリフォニックシンセ。8 centのDetuneを持つ2 Voice Unison Sawが適度な厚みを作りながら各音の音程関係を明確に残す。立ち上がりはパッドより速くスタブより長い中程度の発音で、Ladder Filterの軽いDriveが明るさと丸さのバランスを取る。特定のジャンルや奏法に依存しない汎用コード音。 |
| 28    | **シンセストリングス** | 弦のアンサンブルを連想させる、滑らかで広がりのある合成コード音。16 centのDetuneを持つ5 Voice UnisonとChorusが、複数の電子音が重なった古典的なシンセストリングスらしい均一な厚みを作る。0.4秒の立ち上がりは急激すぎず、押している間は安定した厚みを保ち、離した後にも短い余韻が残る。高域は柔らかな明るさに抑え、コードの背景にも前景にも使える。 |
| 29    | **デジタル・ポリシンセ** | 明瞭で精密な倍音を持つ、現代的なデジタル系コード音。Wavetableの中間Positionで静止させた硬質な倍音構成に、6 centとタイトなDetuneの2 Voice Unisonを合わせ、輪郭の明るさと透明な高域を確保する。アナログポリシンセより輪郭が硬く、複数音を重ねても濁りにくい。プラックのように減衰せず鍵盤を押している間は安定して持続し、速いコード進行でも各和音の切り替わりが明確。 |
| 30    | **シンセブラス・スタブ**   | House、Techno、Synthwaveのコードを一発で鳴らす、太く力強いシンセブラス。深いFilter Envelopeが発音直後の明るく勢いのある立ち上がりを作り、0.5秒ほどかけて丸く減衰する。Ladder FilterのDriveが金管のような芯を加えつつ、古典的なシンセサイザーらしい人工的な質感を保つ。1回のコードが明確な塊として聞こえ、パッドのようには広がり続けない。 |
| 31    | **ハウス・コードスタブ** | HouseやGarage系の反復コードに使いやすい、短くまとまったコード音。Square波の輪郭に速いFilter Envelopeが加わり、発音直後の中高域の筋がすぐ減衰して次のコードのための空間を残す。200HzのHigh Passが低中域の重なりを切り捨て、シンセブラスより軽く金管らしさの弱い質感を作る。4和音を短く連続させても濁らず、リズムの一部としてコードを置ける。 |

## プラック／ベル／マレット

| 34    | **デジタル・クリスタルプラック** | 細く透明な音程の芯に、小さなガラス片を弾いたような輝きが重なるプラック。高い成分ほど速く減衰し、短い余韻に澄んだ響きが残る。強い打鍵で輝きが増し、アルペジオやコードの中でも軽さを保つ。 |
| 35    | **FMベル**       | 明瞭な音程の芯と複雑な金属倍音を持つFMベル。発音直後の明るい金属感がほどけ、丸い音へ移りながら長く減衰する。強い打鍵で倍音が豊かになり、弱い打鍵では穏やかな余韻が残る。 |
| 36    | **グラスベル**      | 澄んだ立ち上がりと細く長い余韻を持つグラスベル。音程に沿う透明な倍音を中心に、かすかな高域の揺らぎが輝きを添える。強弱で明るさが変わり、高い旋律でも雑音的な濁りを抑えた響きを保つ。 |
| 37    | **マリンバ風マレット**  | 木の板を柔らかなマレットで叩いたような、丸く温かい有音程打楽器。短い打撃と中低域の胴鳴りが一体になり、高い成分から速く収まる。低い音では太く、高い音では軽く、強弱を付けた反復や旋律に使いやすい。 |
