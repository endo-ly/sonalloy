# 代表60音

## ベース

| #音源要件 |                   |                                                                                                                                                                                      |
| ----- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1     | **クリーン・サブベース**    | 曲の最低域を安定して支える、滑らかで純度の高い低音。主な音域はC1〜C3付近で、特に低い音域でも音程の中心が明確。単独で派手に聞かせる音というより、キックや他の音色と重ねた際に低域の厚みを自然に補う。音を長く伸ばしても濁りや揺れが目立たず、短く弾いても発音がぼやけない。中高域の成分や左右方向の広がりは控えめで、低域の基準となる性格を持つ。           |
| 2     | **808ベース**        | 808系の低音として認識できる、発音直後の大きな音程下降と、その後に続く深く滑らかな低音を持つ。主な音域はC1〜C3。短い音では特徴的な落下感が明確に現れ、長く伸ばすと下降後の音程が安定して低域を支え続ける。クリーン・サブベースより立ち上がりの存在感が強く、中高域の倍音よりも低域そのものが中心。単音のベースとしても、キックと一体化する低音としても使いやすい。 |
| 3     | **アナログ・ソウベース**    | シンセサイザーらしい太い倍音を持つ、標準的な電子ベース。House、Techno、Synth Popなど幅広い楽曲で使える。発音直後には適度な明るさと勢いがあり、その後は少し丸く落ち着く。低域には十分な芯があり、中域にも小型スピーカーで存在を認識できる程度の成分が残る。極端な歪みや広がりに依存せず、汎用的なシンセベースとして扱いやすい。            |
| 4     | **ショート・プラックベース**  | 8分音符や16分音符を細かく刻むベースラインに適した、短く弾む低音。発音の輪郭が明確で、連続して鳴らした際にも前の音が次の音へ大きく重ならない。長く鍵盤を押した場合でも一定音量で伸び続けず、自然に減衰する。立ち上がりだけのクリック音ではなく、短い時間の中にも低音の芯と音程が十分に残る。                                      |
| 5     | **303系アシッドベース**   | TB-303系を想起させる、鋭い共鳴と大きな音色変化を特徴とするベース。発音直後から時間とともに倍音構成が大きく変わり、独特の粘りやうねりを感じる。主な音域はC1〜C4付近で、反復する短いフレーズとの相性がよい。高い共鳴成分と低域のベース成分が一体になって聞こえ、通常のソウベースとは明確に異なる強い個性を持つ。                         |
| 6     | **FMパンチベース**      | FM系ベースを代表する、硬い立ち上がりと引き締まった低域を持つ音。発音直後にはデジタルらしい複雑で鋭い倍音が現れ、その後は比較的単純で安定した低音へ落ち着く。短いフレーズでも存在感があり、キックと並んだ際にも発音位置が分かりやすい。金属的な要素を含みながらも、ベルほど高い倍音が長く残らず、低音としての音程感が強い。                       |
| 7     | **リースベース**        | Drum & Bass、Techno、Industrial系で使える、太く暗く、内部にゆっくりしたうねりを持つ持続ベース。主な音域はC1〜C3付近。中央には安定した低域の芯があり、その周囲で中低域が揺れるように聞こえる。単純なソウベースより密度が高く、長音では音の内部に継続的な動きが現れる。うねりの中にも基本の音程は明確に残る。                |
| 8     | **デジタル・モーションベース** | 現代的な電子音楽で使える、1音の途中で倍音構成が大きく変化するデジタルベース。低域の基音は安定し、中域から高域の質感が時間とともに動く。短い音にも独特のデジタル感があり、長く伸ばすとより大きな音色変化が現れる。単純な音量変化や周期的なワウとは異なり、音そのものの形が連続的に変形する印象を持つ。                                  |
| 9     | **ウェーブフォールド・グロウルベース** | 低域の安定した芯の上に、折り返されるような荒い倍音変化を重ねた攻撃的なベース。主な音域はC1〜C3付近で、低い音でも基音の位置は明確に残り、中域では唸るような複雑な質感が前面に現れる。長く伸ばすと倍音の密度や明るさがゆっくり変化し、単純な歪みを加えたソウベースより音そのものが連続的に変形する印象が強い。短い音では硬い輪郭を持ち、Bass Music、Industrial、重いElectro系で前面に出せる。 |

## リード

| #音源要件 |                |                                                                                                                                                     |
| ----- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 10    | **アナログ・ソウリード** | メロディやソロに広く使える、標準的なシンセリード。主な音域はC3〜C6付近で、単音の音程と輪郭が明確。適度な太さと明るさを持ちながら、スーパーソウほど巨大には広がらない。高音域でも刺激が強すぎず、低い音域でもベースのような重さには寄りすぎない。汎用的なリードの基準となる音。           |
| 11    | **スーパーソウ・リード** | TranceやEDMを代表する、非常に厚く広がりのあるソウ系リード。単音でも複数の音がわずかにずれて重なっている感覚が明確で、コードでは大きな音の壁を形成する。左右方向にも広く、同時に中央の芯も残る。アナログ・ソウリードより明らかに大規模で華やかで、楽曲の前面を担える。             |
| 12    | **パルス・リード**    | SquareやPulse系を連想させる、細身で明快な電子リード。ゲーム音楽、Electro、Synth Popなどに適する。C3〜C7付近まで音程が明確で、高音域でも音の芯が残る。厚みよりも輪郭を優先し、単純な波形特有の素直な電子音らしさを持つ。ソウ系リードとは倍音の質感がはっきり異なる。   |
| 13    | **FMデジタルリード**  | FM音源らしい硬質で精密な倍音を持つリード。発音直後だけでなく、音を保持している間にもデジタルらしい複雑さが続く。主な音域はC3〜C6付近で、速いフレーズでも音程と発音の輪郭が明確。ベルのように自然減衰する性格ではなく、鍵盤を押している間はリードとして持続する。金属感と明確な音程感を両立する。 |
| 14    | **ハードシンク・リード** | 古典的なシンセサイザーのハードシンクを代表する、鋭く派手な倍音変化を持つリード。基音の音程は安定したまま、上側の倍音が大きく移動して聞こえる。通常のソウリードより攻撃的で、FMリードとも異なる引き裂かれるような質感を持つ。中高音域のソロで特に強い存在感を発揮する。                |
| 15    | **モノ・ポルタメントリード** | 単音のフレーズを滑らかにつなぐ用途に適した、太く前面に出るモノフォニック・リード。離れた音程へ移動した際には瞬時に切り替わらず、前の音から次の音へ短い時間をかけて連続的に移る。音を重ねずに弾いた場合は各音の発音が明確で、レガートではつながりが滑らか。速い旋律でも音程の中心を失わず、ソロやフックで演奏表現を付けやすい。 |
| 16    | **フェイズディストーション・リード** | 基本の音程を保ちながら波形の時間方向の形が強く変形し、鋭く独特な倍音を生むデジタル系リード。主な音域はC3〜C6付近で、通常のパルスやソウより硬く、FMほど金属的ではない中間的な質感を持つ。音を保持している間に変形量が動くと、明るさだけでなく倍音の並び方そのものが変化して聞こえる。速いフレーズでも音程の中心は明確で、80年代的なデジタル感から現代的な攻撃音まで幅広く使える。 |

## パッド／空間音

| #音源要件 |                       |                                                                                                                                              |
| ----- | --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 17    | **ウォーム・アナログパッド**      | コードの背景を柔らかく支える、標準的なパッド。立ち上がりは緩やかで、鍵盤を離した後にも自然な余韻が残る。中低域に適度な厚みがあり、高域は穏やか。C2〜C6程度のコードでも各音の関係が分かり、和音として自然に聞こえる。派手な変化よりも、長時間鳴らしていて邪魔にならない安定感を持つ。 |
| 18    | **ダーク・アンビエントパッド**     | 暗く沈んだ雰囲気を作るパッド。発音直後から明るい成分が前面へ出ず、時間をかけてゆっくり存在感が立ち上がる。低中域を中心に深さがあり、Ambient、Cinematic、暗い電子音楽の背景に適する。倍音そのものが少なく、少し遠くで鳴っているような奥行きを感じる。           |
| 19    | **ブライト・ワイドパッド**       | 明るい高域と大きな左右方向の広がりを持つ華やかなパッド。Pop、Trance、Ambientなどでコードを大きく広げる用途に適する。ウォーム・アナログパッドより明確に明るく、スーパーソウ・リードより立ち上がりが遅く背景へ馴染む。複数音を重ねても透明感と広がりが残る。        |
| 20    | **PWMパッド**            | 音を長く保持した際に、内部の倍音がゆっくり呼吸するように変化する古典的なシンセパッド。音程そのものではなく、音色の厚さや空洞感が周期的に変化して聞こえる。立ち上がりと余韻は長めで、コードの背景として継続的に使いやすい。静止したアナログパッドより内部の動きが明確。          |
| 21    | **ウェーブテーブル・モーションパッド** | 長いコードの中で倍音構成が徐々に別の形へ移り変わるデジタル系パッド。4〜8秒程度の長音では、開始時と後半で音色が明確に変化し、その間が滑らかにつながる。一定周期の揺れより、時間方向に音色が展開していく印象が強い。アナログ系パッドとは異なる人工的で複雑な質感を持つ。         |
| 22    | **ボーカル・フォルマントパッド**    | 「アー」「オー」「ウー」といった母音の共鳴を連想させる合成パッド。コードで鳴らすと合唱を思わせる雰囲気がありながら、明確に電子音として聞こえる。長音の途中で母音の形が変化すると、声の口の形がゆっくり動くような感覚が現れる。複数音を鳴らしても共鳴が鋭く突出せず、柔らかな声質を保つ。 |
| 23    | **アディティブ・ドローン** | 一つの音を長く伸ばした際に、多数の倍音の重なりがゆっくり変化し続ける持続音。明確な反復周期や大きな音量変化には依存せず、音の内部で一部の倍音が浮かび上がったり沈んだりすることで時間的な展開を持つ。低中域には安定した土台があり、その上に細かな高域成分が重なる。AmbientやCinematicの背景として長時間鳴らしても単調になりにくい。 |
| 24    | **グラニュラー・テクスチャパッド** | 細かな音の断片が重なり合いながら持続する、粒状感のある広いパッド。明確な単一波形が伸び続けるのではなく、小さな音の粒が前後や左右に現れることで、長音の内部に絶えず細かな変化が生じる。全体としては安定した和音や音程感を保ちつつ、表面には少し霞んだ質感と空間的な広がりがある。通常のウェーブテーブル・モーションパッドより変化が細かく不規則で、AmbientやCinematicの背景に自然な動きを加える。 |

## キー／ポリシンセ／コード

| #音源要件 |                  |                                                                                                                                                           |
| ----- | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 25    | **FMエレクトリックピアノ** | 1980年代のFM音源を代表するエレクトリックピアノ系の音。発音直後には硬く明るい打撃感があり、その後は暖かく丸い持続音へ移る。単音だけでなく4〜6音程度のコードでも自然にまとまる。強い打鍵では明るく硬く、弱い打鍵では丸く穏やかに聞こえ、演奏の強さが音色へ反映される。                    |
| 26    | **トーンホイール・オルガン** | Hammond系オルガンを連想させる、複数の倍音が規則的に積み重なった持続鍵盤音。発音後に自然減衰するピアノ型とは異なり、鍵盤を押している間はほぼ一定の音量で鳴り続ける。単音では複数の倍音が明確に感じられ、コードでは厚い和音を形成する。素のオルガン音として十分な存在感を持つ。                |
| 27    | **クラシック・アナログポリシンセ** | コード、伴奏、短いメロディのいずれにも使える、標準的なポリフォニック・シンセ。パッドほど立ち上がりが遅くなく、スタブほど短くもない中程度の発音時間を持つ。複数音を重ねると適度に厚い和音になりながら、各音の音程関係は明確に残る。明るさと丸さのバランスがよく、特定のジャンルや奏法に依存しない汎用的なコード音として扱いやすい。 |
| 28    | **シンセストリングス** | 弦楽器のアンサンブルを連想させる、滑らかで広がりのある合成コード音。発音は急激すぎず、鍵盤を押している間は安定した厚みを保ち、離した後には短い余韻が残る。本物の弦楽器を精密に再現する音ではなく、複数の電子音が重なった古典的なシンセストリングスらしい均一さを持つ。高域には柔らかな明るさがあり、コードの背景にも前景にも使える。 |
| 29    | **デジタル・ポリシンセ** | 明瞭で精密な倍音を持つ、現代的なデジタル系コード音。アナログポリシンセより輪郭が硬く、高域に透明な成分があり、複数音を重ねても濁りにくい。プラックのようにすぐ減衰せず、鍵盤を押している間は安定して持続する。速いコード進行でも各和音の切り替わりが明確で、Pop、Electro、ゲーム音楽など幅広い用途に使える。 |
| 30    | **シンセブラス・スタブ**   | House、Techno、Synthwaveなどでコードを一発鳴らすための、太く力強いシンセブラス。発音直後に明るく勢いがあり、その後は短〜中程度の時間で丸く減衰する。パッドのように長く広がり続けず、1回のコードが明確な塊として聞こえる。本物の金管より、古典的なシンセサイザーらしい人工的なブラス感が強い。 |
| 31    | **ハウス・コードスタブ** | HouseやGarage系の反復コードに使いやすい、短くまとまったコード音。発音直後には中高域の輪郭があり、すぐに減衰して次のコードのための空間を残す。シンセブラス・スタブより軽く、金管を連想させる成分は弱い。4和音程度を短く連続して鳴らしても低中域が重なりすぎず、リズムの一部としてコードを配置しやすい。 |

## プラック／ベル／マレット

| 34    | **デジタル・クリスタルプラック** | 透明で明るく、ガラス片を弾いたような印象を持つデジタルプラック。FMプラックより細く透明で、アナログ・プラックより高域がきらびやか。短い音の中にも複雑な高域の響きがあり、ごく短い余韻が残る。Future BassやPop系のアルペジオで埋もれにくく、同時に耳当たりは滑らか。 |
| 35    | **FMベル**       | FM音源を代表する、明確な音程と複雑な金属倍音を持つベル。発音直後には高く複雑な成分が多く、その後は高い成分から先に減衰し、比較的単純な響きへ変化する。音量だけでなく音色そのものが時間とともに丸くなる。単音の音程は明瞭で、同時に整数倍だけでは得られない金属的な響きを持つ。 |
| 36    | **グラスベル**      | ガラスやクリスタルを連想させる、透明で澄んだベル。FMベルより金属的な濁りが少なく、高域に明るい輝きを持つ。発音直後は非常に明瞭で、その後に細い余韻が長く残る。高い音域でも雑音的にならず、幻想的なメロディや装飾音として使いやすい。                      |
| 37    | **マリンバ風マレット**  | 木製の板を叩いたような丸く短い有音程打楽器。発音直後には小さな打撃感があり、その後は低い倍音を中心とした丸い響きが短く残る。ベル類のような長い金属高域は少なく、木質で温かい印象が強い。中低音域では太く、高音域では軽くなり、短い旋律や反復パターンに使いやすい。        |
